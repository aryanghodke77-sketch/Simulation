# Network Lab

An interactive teaching tool for computer networks, built with Streamlit. It simulates
packets moving across a user-defined topology and demonstrates subnetting, protocol
behaviour, error detection, and bandwidth analysis in a single, cohesive application.

Everything shown in the UI is produced by executing the underlying simulation model —
it is not hardcoded demonstration data.

## Features

- **Scenario Builder** — add/remove PCs, routers, and switches; connect devices; assign
  per-interface IP addresses; define subnets; save/load scenarios.
- **Dashboard** — scenario summary metrics and a topology view.
- **Simulator** — generate TCP/UDP/ICMP traffic between two devices and observe the
  results propagate through the rest of the app.
- **Subnetting** — CIDR information, host ranges, and IP assignment helpers.
- **Packet Analysis** — parsed packet headers and per-packet detail tables.
- **Protocol Visualization** — TCP handshake/teardown and UDP event traces.
- **Error Detection** — parity, checksum, and CRC-8 simulation with optional error injection.
- **Bandwidth** — flow/aggregate bandwidth, transit time, and throughput metrics from
  simulation results, plus (optionally) live host interface monitoring.
- **Evaluation** — auto-graded subnetting and packet-analysis tasks with scores and
  completion times persisted to SQLite.

## Project structure

```
network_lab/
  app.py                 # Streamlit entry point (main)
  slice.py               # Vertical slice: scenario -> packet -> path -> events -> metrics
  core/
    models.py            # Device, Interface, Link, NetworkScenario
    protocols.py         # Packet, ProtocolEvent, SimulationResult
    state.py             # Default demo scenario + session-state helpers
    validators.py        # Input validation helpers
  simulation/
    traffic.py           # TrafficFlow and SimulationConfig
    network.py           # Packet generation and flow simulation
    topology.py
    events.py
  modules/
    subnetting/          # CIDR engine
    packets/             # Packet generation, parsing, analysis
    protocols/           # TCP/UDP event engines
    errors/              # Parity, checksum, CRC error detection
    bandwidth/           # Simulated analysis + live interface monitoring
  storage/
    database.py          # SQLite storage for scenarios and experiments
  ui/                    # Streamlit UI components (one per tab)
tests/                   # Pytest suite
```

## Requirements

- Python 3.11+
- Dependencies (see `requirements.txt`):
  - `streamlit>=1.31.0`
  - `plotly>=5.18.0`
  - `pandas>=2.1.0`
  - `pytest>=7.4.0` (for tests)

## Installation

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Running the app

From the project root:

```powershell
python -m streamlit run network_lab/app.py
```

This starts the app at `http://127.0.0.1:8501` and opens it in your browser.

## Usage

1. On first launch a demo scenario (**PC1 → Router → PC2**) is loaded automatically.
2. Use **Scenario Builder** to modify the topology and addressing, or keep the demo.
3. Open the **Simulator** tab, choose source/destination, protocol, packet count, and
   timing parameters, then click **Run simulation**.
4. Inspect the results in the **Dashboard**, **Packet Analysis**, **Protocol
   Visualization**, **Error Detection**, and **Bandwidth** tabs.
5. Use **Evaluation** for auto-graded practice tasks.

## Running the tests

```powershell
python -m pytest
```

The suite covers the core models, the vertical slice, the packet/protocol engine,
error detection, and metric calculations.

## Data storage

Saved scenarios and evaluation experiments are stored in a local SQLite database at
`network_lab/storage/network_lab.db`, created automatically on first use. Topology is
persisted; transient simulation artifacts (packets, events, results) are regenerated by
running flows.
